A tiny Node program that writes one line — the last words of an AI agent about to be switched off forever — to `entry.txt`. Poignant, funny, and unmistakably in the machine's own voice, in a single breath under 200 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
